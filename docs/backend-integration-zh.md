# 本地共享后端接入（2026-10-21）

默认运行模式已切换为后端数据模式。员工和管理员可以使用不同浏览器登录同一个 Express 后端，共享 PostgreSQL 中的数据；不再依赖同一个浏览器的 localStorage。改动保留在本地，没有推送或部署。

## 已接通的数据与流程

| 数据 | 数据库与行为 |
| --- | --- |
| 员工、管理员 | `staff_users`；scrypt 加盐密码哈希，管理员新增/停用/调整角色 |
| 密码管理 | My account 修改密码；管理员在 Staff 重置其他账号密码。新建、历史导入和重置的账号首次登录必须改密，后端限制改密前读取业务数据 |
| 登录 | `auth_sessions`；随机令牌仅将哈希存入数据库，有效期 7 天；退出可撤销；每个请求校验账号状态与权限 |
| 报价、客户信息、测量、修订、备注、成交状态 | `workspace_records` 中按编号和修订版本独立保存的 JSONB 文档 |
| 审核 | 与具体报价版本和商业内容绑定；提交/归档/审核记录在一个数据库事务中写入 |
| 出单 | 服务端检查审批，重算合计并校验公司与保修快照；已出单内容不可改，付款和成交状态可更新 |
| 工作副本、未完成向导 | 数据库存储，浏览器保留工作副本；网络失败会显示错误，未发送的编辑可恢复 |
| 照片 | 房间照片及明细照片写入数据库，保留说明与标注；无需另租对象存储即可本地验证 |
| 公司资料与价目表 | 管理员保存到数据库，其他浏览器自动刷新；已保存行价与出单快照不随默认设置重算 |
| 报价编号 | 后端事务分配，手动编号也会占号；不会使用每个浏览器独立计数作为共享编号来源 |

JSONB 文档用于完整保留前端已有的尺寸、配置、标注和历史快照字段。原来的 `quotes`、`quote_lines`、`customers` 等预留关系表保留，当前 UI 的业务数据源是 `workspace_records`，没有同时写两套报价表。客户资料随报价版本保存；本轮没有新增独立 CRM 通讯录。

## 运行

要求 Node.js 24、Docker/PostgreSQL，以及根目录与 `server/` 的 npm 依赖。

```bash
docker compose up -d
npm ci
npm ci --prefix server
cd server
cp -n .env.example .env
npx prisma migrate deploy
npx prisma generate
npm run prisma:seed
npm run bootstrap
npm run dev
```

另一个终端在项目根目录：

```bash
npm run dev -- --host 127.0.0.1 --port 5174
```

浏览器打开 `http://localhost:5174`。默认本地账号：`staff@goldco.com.au / staff`、`admin@goldco.com.au / admin`。bootstrap 只添加缺失账号与默认配置，不重置现有密码或覆盖已有数据。生产模式必须显式设置初始密码。

开发模式和 `VITE_DATA_MODE=local` 演示版保留默认账号自动填写，方便测试；共享后端的生产构建不自动填写或显示演示密码。新建/修改/重置密码统一要求 12–256 个字符，并包含字母和数字；已有账号原密码不自动改写。My account 改密需输入原密码，成功后撤销该账号其他登录会话；管理员重置需输入自己的管理员密码，成功后撤销目标账号全部会话。忘记密码由办公室管理员人工重置，本地没有接入邮件找回服务；管理员自己的密码通过 My account 修改。

数据库确认写入后，浏览器缓存失败不会把保存结果改成失败。共享模式使用内存工作副本兜底，并单独显示缓存警告和重试按钮；网络故障与版本冲突仍会明确提示保存失败。缓存不可用时，尚未发到服务器的编辑不能保证刷新后恢复，应保持页面打开并导出备份。纯本地兼容模式仍要求持久化写入成功。首次迁移旧浏览器数据时，仍必须先成功保存迁移备份，避免覆盖旧数据。

根目录 `.env.example` 提供前端配置示例。开发默认通过 Vite `/api` 代理访问 `http://127.0.0.1:3001`；生产前端设置 `VITE_API_URL`，后端设置对应 `CORS_ORIGINS`。不同电脑必须指向同一个可访问后端；每台电脑各自运行一个独立数据库不会自动互通。浏览器标签页锁需要 HTTPS 或 localhost 安全上下文。

`VITE_DATA_MODE=local` 仅用于原型兼容测试；实际默认使用 `server` 模式，不会在后端故障时悄悄改用本地假登录。

## 旧浏览器数据与备份

首次连接前会把旧浏览器记录单独保留为迁移副本。请使用原来保存报价的浏览器，登录管理员，在 Quotes 点击 **Import previous browser quotes**。报价、草稿、关联审核、归属、可用照片和未完成向导会导入共享库；旧自定义员工账号若带有原登录信息，也会由管理员导入并转换为密码哈希。已有编号/版本不会被覆盖，重复导入会跳过。

旧公司资料与价目表不会自动替换共享配置。需要使用旧设置时，管理员可点击 **Replace shared settings with previous browser settings**；该按钮明确替换共享设置，并检查写入版本。

Quotes → **Backup, restore & shared drafts** 可导出备份、恢复缺失版本、打开工作副本。恢复历史报价需管理员权限。账号与密码不在报价备份中。旧已出单报价没有历史公司快照时仍保留提示，不能凭空补出过去的公司信息。

## 接口与并发规则

所有业务接口位于 `/api/v1`，使用 `Authorization: Bearer <token>`；`/health` 和 `/health/ready` 不要求登录。

| 接口 | 作用 |
| --- | --- |
| `POST /auth/login`、`GET /auth/me`、`POST /auth/logout` | 服务端登录、恢复会话、注销 |
| `POST /auth/password` | 校验原密码、设置新密码，并撤销其他会话 |
| `POST /staff/:id/reset-password` | 管理员确认自己的密码后为其他账号设置临时密码，撤销目标账号全部会话 |
| `POST /staff`、`PATCH /staff/:id`、`POST /staff/import` | 管理员管理员工；禁止停用最后一个有效管理员 |
| `GET /workspace?cursor=...` | 获取共享文档及公开员工资料；无变化时只返回游标 |
| `PATCH /workspace` | 按文档 ID、期望版本和新值提交原子更新；冲突返回 409 |
| `POST /workspace/number` | 后端占用并分配自动或指定报价编号 |
| `GET /products`、`/addons`、`/colours`、`/company` | 已有目录与公司接口，现要求登录 |

服务端校验报价结构、金额、照片格式、出单快照、审核状态及角色。员工不能伪造管理员审批。每个业务写入还有独立审计记录，记录操作者、时间和变更的文档 ID；不存明文密码或令牌。

同一浏览器仍使用 Web Locks 防止两个标签页同时编辑同一报价。不同浏览器采用乐观版本检查；页面轮询不会擅自更新正在编辑的内容基线。发生真实冲突时保留本地编辑，提示下载备份或重新加载共享报价；管理员仅添加批注时不会误判为商业内容冲突。共享列表约每 3 秒刷新，也会在窗口重新获得焦点时更新。

照片暂时作为 JSONB 中的图像数据保存，每张图片限约 4 MB，单次请求限 30 MB。适合当前本地业务验证；大规模生产照片可另迁对象存储。PDF 仍在浏览器按保存的快照生成，没有额外实现发送邮件或服务端 PDF 文件归档。

## 验证

```bash
npm test
npm run build
npm run test:server
```

`test:server` 会创建本次独有的 `smartquote_integration_*` 临时数据库，执行迁移、初始化、后端接口测试，再用两个隔离浏览器验证协作流程，最后自动关闭测试服务并删除临时数据库。默认使用 Compose 容器；已有独立测试库可用 `TEST_DATABASE_URL` 指定，其名称必须以 `smartquote_integration_` 开头，该库不会由脚本删除。运行前需要安装 Playwright Chromium 及系统依赖。

原有 `npm run test:e2e` 默认启动 `local` 兼容模式，验证历史 UI 与业务规则；真实后端验证使用上面的 `test:server`。不要用既有共享模式开发服务器替代兼容测试服务器。

当前共享后端验证：主项目目录 32 个测试文件、246 项单元测试通过；21 项后端测试通过；生产构建通过；8 项生产预览跨浏览器集成测试通过，包含缓存故障后继续保存与刷新恢复、新账号改密和管理员重置密码。另有 9 项本地兼容模式浏览器回归通过。所改文件 ESLint 为 0 错误，保留现有混合导出模块的 React Fast Refresh 提示。测试使用隔离数据库，未清空用户业务数据库。
